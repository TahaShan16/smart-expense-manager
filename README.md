# Smart Expense Manager 💰

A CLI-based expense tracking app built in Python.

## Features
- User account system (create account, login)
- Add, view, delete expenses
- Spending insights by category
- Smart suggestions based on spending habits
- Persistent JSON storage

## How to run
python main.py

## Tech Used
- Python 3
- OOP (classes, encapsulation)
- File handling (JSON)
- Custom exception handling
